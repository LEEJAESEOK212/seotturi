# New Seotturi

부산·경남 사투리를 의미와 말투를 보존하면서 자연스러운 표준어로 변환한다.

## 현재 단계

설계 및 데이터 확인 단계. MLX 학습 도구와 Hugging Face 도구를 프로젝트 가상환경에 설치했다.
환경 사용법과 모델 정보는 `docs/setup.md`에 기록한다. 실제 데이터 학습은 아직 수행하지 않았다.
Gemma 텍스트용 4비트 모델 다운로드와 GPU 기반 오프라인 문장 생성도 확인했다.
설치 확인 문장에서 말투 변경과 불필요한 표현 추가가 관찰되었으며, 품질 개선은 이후 평가·학습 단계에서 다룬다.
현재 개발 브랜치는 `codex/new-seotturi`다. 저장소 루트의 Python 앱들은 이전 실험 코드다.
5개 지역 데이터 통합과 정확 문맥 중복 정리를 완료했다. 원본 11,720,550개에서 298,548개를 제외하고 11,422,002개를 보존했다. 상세 내용은 [지역별 결과](docs/regional-corpus-results.md)를 참고한다.

## 첫 번째 목표

검수한 평가 문장으로 학습 전 Gemma의 성능을 측정한다. 이후 같은 평가 기준으로 QLoRA 학습 효과를 비교한다.

1. 통합 데이터를 모델 입력 형식으로 변환하고 학습·검증 겹침과 정답 품질을 확인한다.
2. 학습과 분리된 평가 문장으로 학습 전 결과를 기록한다.
3. 50~100스텝 시험 학습으로 속도·최대 메모리·잘림 여부를 측정한다.
4. 측정 결과를 바탕으로 본 학습 규모와 시간을 결정한다. 통합 원본에는 개수 제한이나 비율 조정을 적용하지 않았다.

## 결정한 방향

- 하드웨어: MacBook Pro M4 Pro, GPU 16코어, 통합 메모리 24GB.
- 첫 기준 모델: Gemma 3 4B instruction 모델의 MLX 호환 4비트 버전. 모델 리비전과 확인한 실행 환경은 `docs/setup.md`와 `docs/model-manifest.json`에 기록했다.
- 학습: 원본 가중치를 고정하고 LoRA 어댑터를 SFT로 학습하는 QLoRA.
- 교사 모델 생성 데이터: 부족한 유형에만 사용하고, 검수와 출처 기록을 거쳐 채택한다.
- GRPO: 초기 범위에서 제외. DPO는 검수된 선호 쌍과 명확한 필요가 생기면 재검토한다.
- 첫 구현 범위: 텍스트 변환. 음성 입력과 설명 생성은 변환 품질을 확인한 다음 연결한다.

## 변환 규칙

- 의미, 인물, 숫자, 부정, 시제, 의문 여부, 존댓말·반말 수준을 보존한다.
- 사투리 표현을 필요한 만큼만 바꾼다. 임의로 문어체나 존댓말로 다듬지 않는다.
- 이미 자연스러운 표준어인 문장은 유지한다.
- 문맥 없이는 뜻을 확정하기 어려우면 추측하지 않고 문맥을 요청한다.
- 사투리를 틀리거나 열등한 표현으로 평가하지 않는다.
- 학습과 추론에 같은 작업 지시와 출력 규약을 사용한다.
- 변경 설명은 확정된 변환 결과와 검수된 근거를 바탕으로 별도 처리한다.

## 평가 기준

문장별로 의미 보존, 표준어 자연스러움, 말투 보존, 불필요한 수정, 문맥 요청의 적절성을 기록한다.
문자열 완전 일치만으로 정오를 판정하지 않는다. 여러 자연스러운 정답을 허용한다.
평가셋 정답은 사람이 검수하며, 프롬프트 예시 검색과 학습에 사용하지 않는다.
프롬프트 조정은 개발셋으로 하고 최종 평가셋은 모델 선택 결과 확인에 사용한다.
학습 손실 감소만으로 모델을 채택하지 않는다.
